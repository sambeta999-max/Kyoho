# Maxwell to Ampere class changes

Generated by `../class_diff.py` from NVIDIA's open-gpu-doc headers, annotated with the Eden
register field covering each offset (from `ASSERT_REG_POSITION` in the engine headers):

```sh
python3 class_diff.py clb197.h clc797.h --eden src/video_core/engines/maxwell_3d.h > reports/3d_b197_c797.md
python3 class_diff.py clb1c0.h clc7c0.h --eden src/video_core/engines/kepler_compute.h > reports/compute_b1c0_c7c0.md
python3 class_diff.py clb0b5.h clc7b5.h --eden src/video_core/engines/maxwell_dma.h > reports/dma_b0b5_c7b5.md
python3 class_diff.py clb06f.h clc56f.h --eden src/video_core/engines/puller.h > reports/host_b06f_c56f.md
```

Headers: `classes/3d`, `classes/compute`, `classes/dma-copy` and `classes/host` of
https://github.com/NVIDIA/open-gpu-doc. KeplerCompute asserts few fields, so its annotations are
coarse. The host header mixes in pushbuffer and MEM_OP field values; the `MEM_OP_C/D_*` rows at
0x0000 and 0x0004 of its "Added" table are such values, not methods.

## What Eden reads differently on AMPERE_B (0xC797)

| Eden field | Maxwell B | Ampere B |
|---|---|---|
| `program_region`, `pipelines[i].offset` | `SET_PROGRAM_REGION_A/B` (0x1608) plus a 32-bit offset per stage (0x2004+i*64) | A 64-bit address per stage, `SET_PIPELINE_PROGRAM_ADDRESS_A/B` (0x2014/0x2018+i*64); 0x2004 is reserved and the region methods are gone |
| `index_buffer` end address | `SET_INDEX_BUFFER_C/D` (0x17d0/0x17d4) | Size, `SET_INDEX_BUFFER_SIZE_A/B` (0x0238/0x023c) |
| `vertex_stream_limits` | Limit addresses at 0x1f00+i*8 | Sizes, `SET_VERTEX_STREAM_SIZE_A/B` (0x0600/0x0604+i*8) |
| `bindless_texture_const_buffer_slot` | `SET_BINDLESS_TEXTURE` (0x2608) | Removed; SM86 texture instructions name their constant buffer |
| `select_texture_headers` | `SET_SELECT_MAXWELL_TEXTURE_HEADERS` (0x0f10) | Removed; the texture header format has to be checked separately |
| `pipelines[i].register_count` | 8 bits | 9 bits |
| `draw` (`BEGIN`) | | New `INSTANCE_ITERATE_ENABLE` at bit 31 |
| `report_semaphore` | | New report types (SCG clocks, 64-bit tiled ZPASS, timestamp) |

New 3D methods with no Maxwell counterpart: 64-bit report semaphores (0x0158-0x0168), the
fast draw methods `SET_DRAW_CONTROL_A/B`, `DRAW_INDEX_BUFFER_BEGIN_END_A/B`,
`DRAW_VERTEX_ARRAY_BEGIN_END_A/B` (0x0260-0x0274) and `SET_INSTANCE_COUNT` (0x0220), the
Turing macro engine controls (`SET_MME_VERSION` 0x0234, `MME_DMA_*` 0x0550-0x0574), root tables,
mesh shaders and variable rate shading.

Compute (C7C0) reuses 0x0214/0x0218/0x029c for QMD virtualization and 0x0550-0x0574 for the
macro engine DMA; the shared and local memory window methods are gone. Host (C56F) adds 64-bit
semaphores (`SEM_ADDR_LO/HI`, `SEM_PAYLOAD_LO/HI`, `SEM_EXECUTE`, 0x005c-0x006c) and drops
`FB_FLUSH` and `CRC_CHECK`. Copy (C7B5) keeps its layout and only extends fields.
